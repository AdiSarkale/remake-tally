# Phase 3 — Advanced Manufacturing Control

## WIP / SF
Track product-based WIP quantity, order linkage, status, and unit cost.

## Machines
Machine code, name, work-centre, capacity, hourly rate, status, active state, and maintenance due.

## Downtime
Record machine, start/end, reason code, explanation, maintenance flag, and actor. Open downtime can change machine status.

## Production costing
Store material, labour, machine, and overhead components; total cost; accepted quantity; unit cost; currency; and notes.

## Analytics
Report production, accepted/rejected, scrap, quality ratio, costs, and availability where data supports it. Performance and full OEE remain unavailable until reliable target-cycle-time data is added.
