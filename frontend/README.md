# MiniTally ERP — Frontend

React 19 + TypeScript + Vite + npm client for the FastAPI backend in `../backend`.

## Run

```bash
cd frontend
cp .env.example .env        # set VITE_API_URL (default http://localhost:8000)
npm install
npm run dev                 # http://localhost:5173
```

`npm run typecheck` · `npm run build` (typecheck + production build to `dist/`) · `npm run preview`

## Stack
- Routing: TanStack Router (file-based, `src/routes`, `routeTree.gen.ts` generated by the Vite plugin)
- Data: TanStack Query hooks in `src/lib/api/hooks.ts`, typed contracts in `src/lib/api/types.ts` mirroring backend Pydantic schemas
- Auth: JWT Bearer from `/api/v1/auth/login`, stored in localStorage (`minitally.token`); 401 → sign-out
- UI: Tailwind CSS v4 + shadcn/ui (Radix), IBM Plex, dark industrial theme

## Modules
Dashboard · Sales (customers, quotations, sales orders, deliveries, dispatches, invoices) · Procurement (requisition view, POs, GRNs, suppliers) · Inventory (stock, materials, products, scrap types, movements, locations) · Production (orders, auto/manual employee assignment, allocation, entries, scrap, BOM, routings, work centers) · Finance (receivables, payables, receipts, payments) · Employees (production-side).

## Known gaps
- Purchase requisition is a computed view (no backend entity).
- Employee edit/deactivate not implemented.
- Reports and Settings are placeholders.
- Payroll/attendance/leave are out of scope.
